SkynetAccessibility Video Subtitle is an AI-powered video accessibility module for Odoo that automatically generates synchronized subtitles for website videos using advanced speech recognition.

It injects the Skynet Video Subtitle front-end widget script on every public website page and provides administrators with an analytics dashboard containing usage, video library, and plan package information. This helps website owners publish accessible multimedia content without manually creating captions.

The solution supports accessibility initiatives aligned with WCAG 2.1, WCAG 2.2, ADA, Section 508, and EAA EN 301 549, where applicable.

Features

  • Quick subtitle processing
  • Compatible with YouTube, Vimeo, and self-hosted video platforms
  • Audio and video summary report
  • Simple installation and configuration
  • Support for existing and newly published videos
  • Support for 50+ languages
  • Unlimited video subtitle processing throughout the selected plan

Ideal For

Blog videos, news videos, tutorials, landing page videos, announcements, interviews, webinars, and embedded media.

Installation

  1. Go to Settings → Apps.
  2. Enable Developer Mode if the Import Module option is not visible.
  3. Click Import Module and upload the module ZIP file.
  4. Once installed, the widget script is automatically injected into the public website pages.
  5. Access the module dashboard from Settings → SkynetAccessibility Video Subtitle → Dashboard.
